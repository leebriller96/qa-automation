# /qa — 통합 테스트 자동화 + 결함/위험 레포트

서비스 코드의 통합 테스트를 자동으로 생성·실행하고, 잠재 결함과 위험을 정리한 레포트를 만드는 명령입니다.

모드: `$ARGUMENTS` (비어 있으면 `full`로 처리)

## 수행 절차

아래 절차를 순서대로 수행하세요. 상세 방법론은 `.claude/skills/test-automation/SKILL.md`를 반드시 먼저 읽고 따릅니다.

### 1단계 — 분석 대상 확보
- `input/` 디렉토리를 확인합니다. 코드가 있으면 그것을 대상으로 합니다.
- `input/`이 비어 있고 사용자가 코드를 붙여넣었다면 그 코드를 대상으로 합니다.
- 둘 다 없으면 "input/에 서비스 코드를 넣거나 코드를 붙여넣어 주세요"라고 안내하고 중단합니다.

### 2단계 — 서비스/통합 지점 인벤토리
- 디렉토리 전체를 훑어 서비스/모듈, 진입점(HTTP 라우트, 핸들러, CLI, 컨슈머)을 식별합니다.
- 통합 지점을 찾습니다: DB 접근, 외부 API 호출, 메시지 큐, 파일/네트워크 I/O, 서비스 간 호출.
- 언어/프레임워크와 기존 테스트 유무, 의존성 매니페스트를 파악합니다.

### 3단계 — 테스트 환경 준비 (full / run-only)
- 의존성 설치, 테스트 설정(테스트 DB/픽스처/환경변수)을 준비합니다.
- 외부 의존성은 가능하면 테스트 더블 또는 testcontainers로 대체합니다.
- 환경 구성이 불가능하면 그 사실과 누락된 요소를 기록하고, `generate-only`로 자동 폴백합니다.

### 4단계 — 통합 테스트 생성 (full / generate-only)
- SKILL.md의 언어별 가이드에 따라 통합 테스트를 생성합니다.
- 행복 경로 + 경계/예외 + 통합 실패 시나리오(의존성 실패, 부분 실패, 롤백 등)를 포함합니다.
- 생성한 테스트는 `input/<서비스>/tests/`(또는 관례 위치)에 저장합니다.

### 5단계 — 테스트 실행 (full / run-only)
- `tools/run_tests.sh <대상경로>`로 언어를 감지해 테스트를 실행하고 결과를 수집합니다.
- 통과/실패/에러를 집계하고, 실패는 원인(스택트레이스 요약)을 기록합니다.
- 실행 불가(러너/의존성 부재) 시 그 사실을 명확히 남기고 정적 위험 분석으로 보완합니다.

### 6단계 — 결함/위험 분석
- 실패한 테스트는 결함(Defect)으로 분류하고 재현 조건과 추정 원인을 기술합니다.
- 미검증 통합 경로, 경계/동시성/데이터 무결성 위험, 에러 처리 누락, 계약 불일치는 위험(Risk)으로 분류합니다.
- CLAUDE.md의 등급 기준으로 심각도를 매깁니다.

### 7단계 — 레포트 생성
- `templates/report_template.md` 구조로 Markdown 레포트를 작성합니다.
- 파일명: `reports/<KST타임스탬프>_qa_report.md`
  - 타임스탬프: `TZ=Asia/Seoul date '+%y%m%d%H%M'` (윈도우: `Get-Date -Format 'yyMMddHHmm'`)
- 빌더로 HTML을 생성합니다. (운영체제에 맞게)
  - 윈도우: `python tools/build_report.py reports/<...>.md`
  - macOS/Linux: `python3 tools/build_report.py reports/<...>.md`
  - `markdown` 미설치 에러 시 `python -m pip install markdown` 후 재실행.
- `.html` 생성 여부를 확인합니다. PDF는 HTML을 브라우저에서 Ctrl+P로 저장하도록 안내합니다.

### 8단계 — 요약 보고
- 채팅에 두괄식으로 요약합니다: 서비스 수, 생성/실행한 테스트 수, 통과·실패, 발견 결함 수, Top 3 우선 조치.
- 생성된 레포트 경로(MD/HTML)와 생성된 테스트 위치를 안내합니다.

## 주의
- 테스트를 통과시키기 위해 검증을 약화시키지 않습니다. 실패는 실패대로 정직하게 보고합니다.
- 외부 시스템에 부수효과를 주는 테스트(실서버 호출, 실데이터 변경)는 만들지 않습니다. 격리된 테스트 환경을 전제로 합니다.
- 모든 출력은 한글로 작성합니다.
